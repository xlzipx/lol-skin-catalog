===========================================================
  LoL SKIN CATALOG
===========================================================

Builds a PDF catalog of every League of Legends skin you own,
including splash art, rarity tiers and chroma counts.
Plus an Excel sheet and a CSV list.

-----------------------------------------------------------
  ENGLISH
-----------------------------------------------------------

HOW TO RUN

  1. Start League of Legends and log in.
     The lobby is enough - you do not have to play.
     Leave the client open.

  2. Unzip this archive somewhere on your disk.
     Run it unzipped, not from inside the ZIP.

  3. Double-click LoL-Skin-Catalog.exe

  4. Wait. The first run takes a few minutes while the
     artwork downloads. The PDF opens by itself when done.

WHAT YOU GET (next to the .exe)

  Skins.pdf     the catalog with pictures - the main thing
  Skins.xlsx    filterable table with thumbnails
  skins.csv     plain list, no images
  splashes\     splash art as individual images

  Skins.pdf and Skins.xlsx are self-contained - pictures are
  inside the file, so you can forward either one.

WINDOWS MAY WARN YOU

  On first launch you may see a blue window saying
  "Windows protected your PC".

  That is because the program is not signed with a paid
  certificate, not because it is harmful. Click "More info"
  and then "Run anyway".

  If your antivirus deletes it outright, the "no-exe" folder
  holds the same program as Python scripts - see
  no-exe\README.md.

GOOD TO KNOW

  - It only reads data from the League client running on your
    own computer. It sends nothing anywhere, writes nothing to
    the game, and never asks for your password. Artwork is
    downloaded from the public Community Dragon mirror.

  - It finds the client by itself, wherever the game is
    installed. If it says it cannot connect, the client is
    almost certainly not running yet - wait until you are in
    the lobby and start it again.
    Last resort: find the file "lockfile" in your League of
    Legends folder and drag it onto the .exe.

  - Default champion skins are not counted, only real skins.

  - For Czech output run it from a command line with:
        LoL-Skin-Catalog.exe --lang cs

-----------------------------------------------------------
  CESKY
-----------------------------------------------------------

JAK NA TO

  1. Spust League of Legends a prihlas se.
     Staci lobby - hrat nemusis. Klient nech otevreny.

  2. Rozbal tenhle ZIP nekam k sobe na disk.
     Spoustej to az rozbalene, ne primo ze ZIPu.

  3. Dvojklik na LoL-Skin-Catalog.exe

  4. Pockej. Poprve to trva par minut, nez se stahnou
     obrazky. Az to dobehne, PDF se samo otevre.

CO SE VYTVORI (vedle toho .exe)

  Skins.pdf     katalog s obrazky - tohle je to hlavni
  Skins.xlsx    filtrovatelna tabulka s nahledy
  skins.csv     prosty seznam bez obrazku
  splashes\     splash arty jako jednotlive obrazky

  Skins.pdf a Skins.xlsx jsou sobestacne - obrazky jsou
  primo uvnitr souboru, takze je muzes preposlat dal.

WINDOWS TE MOZNA VAROVAT

  Pri prvnim spusteni se muze objevit modre okno
  "Windows ochranil vas pocitac".

  Je to proto, ze program neni podepsany placenym
  certifikatem, ne proto, ze by byl skodlivy. Klikni na
  "Dalsi informace" a pak na "Presto spustit".

  Kdyby ti to antivirus rovnou smazal, ve slozce "no-exe"
  jsou stejne fungujici Python skripty - postup je
  v souboru no-exe\README.cs.md.

DOBRE VEDET

  - Program si jenom cte data z tveho klienta, ktery bezi
    u tebe v pocitaci. Nikam nic neodesila, do hry nic
    nezapisuje a heslo po tobe nechce. Obrazky stahuje
    z verejneho Community Dragonu.

  - Klienta si najde sam, je jedno kam mas hru
    nainstalovanou. Kdyz hlasi, ze se nemuze spojit, skoro
    vzdy to znamena, ze klient jeste nebezi - pockej, az
    budes v lobby, a spust to znovu.
    Uplna zaloha: najdi ve slozce s hrou soubor "lockfile"
    a pretahni ho mysi na to .exe.

  - Zakladni vzhledy sampionu se nepocitaji, jen skutecne
    skiny.

  - Vystup je automaticky v cestine, kdyz mas cesky Windows.
    Anglicky natvrdo:
        LoL-Skin-Catalog.exe --lang en
